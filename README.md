# Prem Mobile — Pinto Park, Gwalior 📱✨

> **“Deal Aise Jo Deewana Bana De 🔥”**

Official website and digital store for **Prem Mobile**, a premier local electronics and mobile accessories destination in Gwalior (M.P.).

---

## 🚀 Features

- **Widescreen Landscape Hero Slider**: High-impact promotional hero banners with instant WhatsApp ordering and offer explorations.
- **Dynamic Product Catalog**: Mobiles, earbuds, smartwatches, chargers, cables, sound systems, and lifestyle tech gadgets.
- **WhatsApp Ordering**: 1-click WhatsApp order flow connected directly to store number (`+91 8770559251`).
- **Interactive Deal Posters**: Promotional grids and special offers.
- **Local Store Locator & Map**: Address details for Pinto Park, Morar, Gwalior with live Google Maps integration.
- **Fast & Responsive**: Built with Vite, React, and Tailwind CSS.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS + Lucide Icons
- **Routing**: React Router DOM
- **Deployment Ready**: Vercel configuration included

---

## 📦 Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```
